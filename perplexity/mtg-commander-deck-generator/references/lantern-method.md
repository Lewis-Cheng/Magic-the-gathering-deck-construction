# Lantern / Endless Atlas (research layer)

Public UI: https://stoken.games/stack/lantern/lantern.html  
Map: https://stoken.games/stack/card-atlas.html  
Method: https://stoken.games/stack/methodology.html

UMAP of ~32k cards, six lenses. This skill uses three, in order:

1. **Deckmates** — co-occurrence / built-together.
2. **What it does** — Oracle-text / function similarity.
3. **Combos** — combo-piece proximity.

Type labels (creature, instant, artifact) are weak. Do not pick a card because it shares a type with the commander.

Coplay (one card’s text names another) is a note, not a reason to force a swap.

If the Agent cannot load Atlas coordinates this run, keep this order using cited pages, and set `atlas_fetch: failed`.
